## Start here

### AI Social Media Toolkit

My main open-source project: a **creator-operations toolkit for AI agents and social-media workflows**.

It currently includes:

- **17 portable Agent Skills**
- **10 runnable Python tools**
- **8 GitHub Actions workflows**
- creator workflows for **Reels, Pinterest, content repurposing, influencer fit, brand voice and digital visibility**
- research layers for **GitHub, Maps/local intelligence, commercial opportunities and Pinterest**
- validation, evidence rules and a bounded **Self-Healing Automation Guardian**
- free non-developer starter materials for prompts, assistants, automations, Pinterest, Reels and Canva + AI

### See proof in two minutes

No API key or third-party Python package is required:

```bash
git clone https://github.com/alptugharun/ai-social-media-toolkit.git
cd ai-social-media-toolkit
python tools/two_minute_demo.py
```

The bundled demo data is synthetic and clearly labeled. You can also [preview the expected output](https://github.com/alptugharun/ai-social-media-toolkit/blob/main/examples/TWO-MINUTE-DEMO-OUTPUT.md) before cloning.

### Install the Agent Skills

```bash
npx skills add alptugharun/ai-social-media-toolkit
```

Browse first:

```bash
npx skills add alptugharun/ai-social-media-toolkit --list
```

Run one workflow without permanently installing the full toolkit:

```bash
npx skills use alptugharun/ai-social-media-toolkit --skill signal-to-content
```

## What makes this project different

The project is built around one operating loop:

**Signal → Research → Strategy → Content → Creative → Review → Distribution → Measurement → Winner Expansion**

That means the repository is not optimized for the highest possible skill count.

The priorities are:

1. useful workflows
2. reproducible examples
3. evidence-aware outputs
4. low-friction installation
5. real external use
6. measured improvement

When a workflow does not earn proof, it should not become a product just because it can be built.
